The sidebar calls this page AI forecasts. It is not: calling arithmetic "AI" would be a claim about how the numbers were produced, and a wrong one. What the page really does is score the arithmetic, which is what would make a model worth adding later.
How the scoring works
Only months that have finished are scored — a month still running has partial actuals, and comparing a whole month's forecast against half a month's ledger would report every forecast as wildly optimistic. Only committed forecasts are scored, because a draft was never relied on. Actuals are read through the same definition the profit and loss uses, so a forecast cannot be scored against a figure that disagrees with the reports.
Why there are two measures
Bias is the signed difference: it says whether a method runs high or low, which is what matters when planning. Absolute error ignores direction: it says how far out the figures were month by month. A method that is wildly wrong in both directions can have almost no bias while being useless, so reporting only bias would hide exactly that.
