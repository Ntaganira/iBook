Settings a connection would need.

Nothing is sent and nothing is received
This application has no outbound connection of any kind: no client, no scheduled polling and no endpoint for a provider to call back. Filling this page in records the settings a connection would need. It does not create one, and nothing here will reach the provider.
What is still missing
Credentials from the provider.
No key is stored here
There is no field for a key and no column to keep one in. What is recorded is the name of the environment variable that holds it, such as MOMO_API_KEY. The name is not sensitive; the key itself never reaches this database, its backups or any page. That means somebody has to set the variable on the server, and this application cannot check whether they got it right, because it never reads the value.

There is nothing to configure here yet.

This application serves rendered pages and exposes no JSON endpoints, so an API key would grant access to nothing. A key that opens nothing is worse than no key, because somebody would believe they had given something access.
