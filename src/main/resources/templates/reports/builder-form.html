What the report is

A movement asks what happened between two dates, which is the only sensible question for revenue and expense. A balance asks what an account stood at on a date, which is meaningless for a trading account.
The prior period is the same number of days immediately before, not the same dates a month back — that would silently drop a day on a 31-day month.
Off by default: forty rows of which thirty-five are zero hide the five that matter. Turn it on when the shape of the report is the point, such as a return whose lines must all appear.

The rows

Accounts are selected by type and code range, never by naming them one at a time.
Row Label Account type Code from Code to Itemise Flip sign
An Accounts row selects; a Heading prints a label; a Subtotal adds up every Accounts row since the last subtotal and then starts again; a Spacer leaves a gap.
Itemise lists each account on its own line. Turn it off and the row prints as a single figure under its label — the same selection either way.
Flip sign is for an account that sits with its neighbours but works against them, such as a contra-revenue account that reduces income rather than adding to it.
