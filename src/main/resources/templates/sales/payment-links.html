Gateway settings
These are not payment links
A payment link is issued by a gateway, which collects the money and reports back. There is no gateway here, so no link is produced. What this page does instead is compose the payment instructions and record that they went out — the part a gateway was only ever a convenience for. You send them yourself.
A request is not a payment
Recording a request does not touch the ledger, does not reduce what the customer owes, and does not appear in the invoice's balance. Money is recorded when a receipt is entered against the invoice, and not before. Whether a request has been settled is read off the invoice each time this page is opened, so it cannot drift away from the ledger.
No collection channel is configured
Nothing has been recorded for a gateway, MTN MoMo or Airtel Money, so there is no merchant code to suggest and the "pay to" field has to be filled in by hand. Recording one would fill it in for you — it would still collect nothing.

Ask a customer to pay

Composes the message and records that it went out. It does not send it.
Only issued invoices with something still owing appear. A draft cannot be asked about, because the customer has not been billed and the figure may still change.
Leave empty to ask for the whole of what is outstanding. More than that is refused: a request for more than is owed is asking for an overpayment somebody then has to refund or carry.
The MoMo code or account number the customer sends to. Filled in from the recorded merchant code where there is one, and left blank rather than guessed where there is not.
Defaults to the invoice number. It is what makes the receipt matchable to the invoice later, so a blank one costs somebody an afternoon at reconciliation.
